# Modelos 3D — APEX Supercar Builder

Descarga los modelos GLB y colócalos aquí con estos nombres exactos:

## Archivos necesarios
- `ferrari.glb`
- `lamborghini.glb`
- `porsche.glb`
- `mclaren.glb`
- `bugatti.glb`

## Fuentes gratuitas (licencia CC-BY)

### Sketchfab (mejor calidad)
1. Ve a sketchfab.com
2. Busca el modelo (ej: "Ferrari F8 Tributo")
3. Filtra por: Free + Downloadable
4. Descarga como GLB
5. Renombra el archivo

## Nota sobre materiales
El viewer detecta automáticamente los meshes de carrocería por nombre.
Si el color no se aplica correctamente, el sistema usa los 5 meshes más grandes.
El fallback procedural se activa automáticamente si el .glb no está disponible.
